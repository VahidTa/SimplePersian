# فارسی ساده (Simple Persian)

این مخزن یک مهارت و مجموعه دستورالعمل برای عامل‌های کدنویسی ارائه می‌دهد. عامل‌های کدنویسی با این قانون‌ها متن‌های فنی و پاسخ‌های گفتگوی فارسی را روشن و بی‌ابهام می‌نویسند. ما این قانون‌ها را با الهام از استاندارد [ASD-STE100](https://www.asd-ste100.org/) و پروژهٔ [AminBlg/SimpleEnglish](https://github.com/AminBlg/SimpleEnglish) ساختیم.

این مهارت و اسکریپت‌های بررسی خودکار (hook، برنامه‌ای که هنگام یک رویداد اجرا می‌شود) فقط برای متن‌های فارسی کار می‌کنند. ابزار بررسی خودکار، متن‌های انگلیسی و پاسخ‌های انگلیسی را تشخیص می‌دهد و بدون تغییر از آن‌ها می‌گذرد.

[English README](README.md)

## نصب

برای نصب مهارت در هر عامل سازگار با استاندارد [Agent Skills](https://agentskills.io)، این دستور را اجرا کنید:

```bash
npx skills add VahidTa/SimplePersian
```

برای نصب افزونهٔ Claude Code همراه با hook نشست و سبک خروجی، این دو دستور را اجرا کنید:

```bash
claude plugin marketplace add VahidTa/SimplePersian
claude plugin install simple-persian@simple-persian
```

برای نصب افزونهٔ Codex همراه با hook آغاز نشست، این دو دستور را اجرا کنید:

```bash
codex plugin marketplace add VahidTa/SimplePersian
codex plugin add simple-persian@simple-persian
```

اگر ابزار شما از مهارت پشتیبانی نمی‌کند، قانون‌ها را از [`prompts/system-prompt.md`](prompts/system-prompt.md) در پرامپت سیستم یا `.cursorrules` کپی کنید.

## نمونهٔ پیش و پس از بازنویسی

دو بند زیر تفاوت خروجی معمولی هوش مصنوعی و خروجی مطابق قانون‌های Simple Persian را نشان می‌دهند.

متن معمولی هوش مصنوعی:

> ابزار sqlpipe یک راه‌حل قدرتمند و جامع است که به شما امکان می‌دهد به‌طور یکپارچه جداول Postgres را به S3 منتقل نمایید. قبل از شروع، بهتر است اطمینان حاصل کنید که دسترسی‌های AWS شما به‌درستی پیکربندی شده‌اند — این امر بسیار حیاتی می‌باشد.

متن با قانون‌های Simple Persian:

> ابزار `sqlpipe` جدول‌های Postgres را به S3 کپی می‌کند و به یک فایل پیکربندی نیاز دارد.
>
> پیش از شروع، مطمئن شوید که گواهی‌های AWS شما درست هستند. اگر گواهی‌ها نادرست باشند، سرویس S3 بارگذاری را با خطای دسترسی رد می‌کند.

در فایل [`examples/before-after.md`](examples/before-after.md) پنج نمونهٔ کامل دیگر می‌بینید. این نمونه‌ها متن معرفی، عیب‌یابی، پیام خطا، گزارش رویداد و یادداشت انتشار را پوشش می‌دهند.

## خلاصهٔ قانون‌ها

این مهارت دو قالب جداگانه دارد: متن سند و پاسخ در گفتگو.

پاسخ در گفتگو، در همهٔ حالت‌ها، از این قانون‌ها پیروی می‌کند:

| قانون | آنچه حذف می‌کند |
|---|---|
| نثر پیوسته به‌عنوان پیش‌فرض (فهرست و جدول فقط برای دادهٔ هم‌شکل) | دیوار قالب‌بندی دور پاسخ کوتاه |
| پاسخ مستقیم در نخستین جمله | مقدمه‌چینی و تکرار پرسش |
| نبودن خط تیرهٔ بلند (`—`) | بریدن جمله و پنهان کردن رابطه |
| تعریف هر اصطلاح مفهومی در نخستین کاربرد | واژه‌های تخصصی بی‌توضیح |
| فارسی معیار بدون آغازگر و پایان‌بندی تعارف‌آمیز | محاوره، `سوال خوبی است` و `امیدوارم مفید بوده باشد` |

نوشتن و بازنویسی سندهای فنی (README، راهنما، پیام خطا و یادداشت انتشار) از این قانون‌ها پیروی می‌کند:

| قانون | آنچه حذف می‌کند |
|---|---|
| بیشینه ۲۰ واژه در جملهٔ دستوری و ۲۵ واژه در جملهٔ توصیفی | جمله‌های دراز و خسته‌کننده |
| آوردن شرط پیش از دستور با ویرگول فارسی (`،`) | شرط انتهای جمله که خواننده دیر می‌بیند |
| زمان ساده و ساختار معلوم بدون `توسط` و `گردید` | کنشگر پنهان و فعل اداری |
| نبودن فعل تردید (`ممکن است`، `شاید`، `بهتر است`، `توصیه می‌شود`) | دستورهای مبهم و غیراجرایی |
| نویسه‌های `ی` و `ک`، `،` و `؟`، و نیم‌فاصلهٔ درست | نویسه‌های عربی و خطای املایی |
| یک واژه برای یک معنا و پرهیز از فینگلیش (`چک کنید`، `کانفیگ`) | چندنامی و واژه‌های آمیخته |
| زنجیرهٔ اضافه با بیشینه سه اسم | عبارت‌های اسمی فشرده |
| بیان واقعیت بدون بزرگ‌نمایی (`به‌طور یکپارچه`، `قدرتمند`، `حیاتی`) | واژه‌های تبلیغاتی بی‌اطلاع |

این مهارت دو حالت دارد: حالت ساده (پیش‌فرض) و حالت سخت‌گیرانه. حالت سخت‌گیرانه زمانی فعال می‌شود که کاربر عبارت `واژگان کنترل‌شده` یا `STE` را بنویسد. این حالت فهرست واژه‌ها و پیونددهنده‌ها را از فایل [`strict-vocabulary.md`](skills/simple-persian/references/strict-vocabulary.md) روی سند اعمال می‌کند. پاسخ گفتگو در همهٔ حالت‌ها ساده می‌ماند.

## ابزار بررسی خودکار و آزمون‌ها

اسکریپت `evals/sp_lint.py` متن فارسی را از نظر نقض قانون‌های مکانیکی بررسی می‌کند. این اسکریپت طول جمله، فعل اداری، محاوره، فعل تردید، فینگلیش، خطای املایی و واژه‌های کلیشه‌ای را می‌شمارد. برای بررسی یک سند یا یک پاسخ گفتگو، یکی از این دستورها را اجرا کنید:

```bash
python3 evals/sp_lint.py --self-test
python3 evals/sp_lint.py --type descriptive --detail path/to/doc.md
python3 evals/sp_lint.py --type reply path/to/reply.txt
```

برای اجرای آزمون‌های hook و اطمینان از هم‌خوانی فایل‌ها، این دو دستور را اجرا کنید:

```bash
node --test src/hooks/simple-persian-activate.test.js
python3 src/hooks/test_lint_hook.py
```
