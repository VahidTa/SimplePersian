# فارسی ساده (Simple Persian)

یک مهارت و مجموعه دستورالعمل برای عامل‌های کدنویسی که متن‌های فنی فارسی و پاسخ‌های گفتگو را ساده، دقیق و بدون حشو می‌نویسد. این پروژه از استاندارد [ASD-STE100](https://www.asd-ste100.org/) و پروژهٔ [AminBlg/SimpleEnglish](https://github.com/AminBlg/SimpleEnglish) الهام گرفته است و زیر مجوز Apache-2.0 منتشر می‌شود.

[English README](README.md)

## دامنهٔ اجرا

این مهارت و قلاب‌های همراه آن فقط زمانی فعال می‌شوند که به زبان فارسی می‌نویسید، بازنویسی می‌کنید یا پاسخ می‌دهید. ابزار بررسی خودکار متن‌های انگلیسی و پاسخ‌های انگلیسی را تشخیص می‌دهد و بدون تغییر یا اخطار از آن‌ها می‌گذرد.

## نصب

در هر عامل سازگار با استاندارد [Agent Skills](https://agentskills.io):

```bash
npx skills add VahidTa/SimplePersian
```

برای نصب افزونهٔ Claude Code همراه با قلاب‌های نشست و سبک خروجی:

```bash
claude plugin marketplace add VahidTa/SimplePersian
claude plugin install simple-persian@simple-persian
```

برای نصب افزونهٔ Codex همراه با قلاب آغاز نشست:

```bash
codex plugin marketplace add VahidTa/SimplePersian
codex plugin add simple-persian@simple-persian
```

اگر ابزار شما از مهارت پشتیبانی نمی‌کند، بخش قانون‌ها را از فایل [`prompts/system-prompt.md`](prompts/system-prompt.md) در پرامپت سیستم، `AGENTS.md` یا `.cursorrules` بگذارید.

## نمونهٔ پیش و پس از بازنویسی

متن معمولی هوش مصنوعی:

> ابزار sqlpipe یک راه‌حل قدرتمند و جامع است که به شما امکان می‌دهد به‌طور یکپارچه جداول Postgres را به S3 منتقل نمایید. قبل از شروع، بهتر است اطمینان حاصل کنید که دسترسی‌های AWS شما به‌درستی پیکربندی شده‌اند — این امر بسیار حیاتی می‌باشد.

متن با قانون‌های Simple Persian:

> ابزار `sqlpipe` جدول‌های Postgres را به S3 کپی می‌کند و به یک فایل پیکربندی نیاز دارد.
>
> پیش از شروع، مطمئن شوید که گواهی‌های AWS شما درست هستند. اگر گواهی‌ها نادرست باشند، سرویس S3 بارگذاری را با خطای دسترسی رد می‌کند.

نمونه‌های بیشتر برای README، عیب‌یابی، پیام خطا، گزارش رویداد و یادداشت انتشار در [`examples/before-after.md`](examples/before-after.md) آمده است.

## خلاصهٔ قانون‌ها

این مهارت دو قالب جداگانه دارد: متن سند و پاسخ در گفتگو.

قانون‌های پاسخ در گفتگو:

- پاسخ را به صورت نثر پیوسته بنویسید. فهرست یا جدول فقط برای محتوای دارای همان ساختار مجاز است. از متن ضخیم استفاده نکنید.
- نخستین جمله پاسخ یا نتیجه را می‌دهد. پرسش را تکرار نکنید.
- از خط تیرهٔ بلند استفاده نکنید. رابطه را نام ببرید یا دو جمله بنویسید.
- هر اصطلاح مفهومی را در نخستین کاربرد در چند واژه تعریف کنید، نه نام محصول را.
- فارسی معیار بنویسید. واژه‌های محاوره‌ای، آغازگرهای تعارف‌آمیز و پایان‌بندی‌های کلیشه‌ای را حذف کنید.

قانون‌های متن و مستندات:

- هر جمله در متن دستوری بیشینه ۲۰ واژه و در متن توصیفی بیشینه ۲۵ واژه دارد.
- شرط را پیش از دستور بیاورید و با ویرگول فارسی جدا کنید.
- زمان ساده و ساختار معلوم بنویسید. ساختار مجهول با `توسط` و فعل‌های اداری (`می‌باشد`، `گردید`، `نمایید`) ممنوع است.
- از فعل‌های تردید (`ممکن است`، `شاید`، `بهتر است`، `توصیه می‌شود`) استفاده نکنید.
- نویسه‌های استاندارد فارسی (`ی`، `ک`)، نشانه‌گذاری فارسی (`،`، `؟`) و نیم‌فاصلهٔ درست را رعایت کنید.
- برای یک مفهوم در کل سند فقط یک واژه به کار ببرید و از فعل‌های فینگلیش دوری کنید.
- زنجیرهٔ اضافه را بیش از سه اسم نکشید و با حرف اضافه بشکنید.
- واژه‌های بی‌اطلاع و بزرگ‌نمایی را حذف کنید و واقعیت را مستقیم بگویید.

دو حالت وجود دارد: حالت ساده (پیش‌فرض) و حالت سخت‌گیرانه. حالت سخت‌گیرانه هنگام نام بردن `واژگان کنترل‌شده` یا `STE`، جدول فعل‌ها و پیونددهنده‌های [`strict-vocabulary.md`](skills/simple-persian/references/strict-vocabulary.md) را روی سند اعمال می‌کند. پاسخ گفتگو در همهٔ حالت‌ها ساده می‌ماند.

## ابزار بررسی خودکار و آزمون‌ها

اسکریپت `evals/sp_lint.py` متن فارسی را از نظر نقض قانون‌های مکانیکی بررسی می‌کند:

```bash
python3 evals/sp_lint.py --self-test
python3 evals/sp_lint.py --type descriptive --detail path/to/doc.md
python3 evals/sp_lint.py --type reply path/to/reply.txt
```

برای اجرای آزمون قلاب‌ها و اطمینان از هم‌خوانی فایل‌ها:

```bash
node --test src/hooks/simple-persian-activate.test.js
python3 src/hooks/test_lint_hook.py
```
